# 画语 Canvas 通用设计平台需求文档

- 版本：v0.1（需求草案）
- 日期：2026-11-04
- 范围：通用平面设计、线上传播与印刷交付

## 1. 产品目标与范围

让用户通过描述需求、上传素材和持续沟通，完成从内容整理、视觉设计、精细修改到专业文件下载的完整流程。适用于海报、宣传页、活动物料、社交媒体配图、菜单、价目表及多页图文物料等场景。

平台应具备通用设计能力，通过不同设计技能提供场景方法。菜单是应用场景之一；A4 是尺寸预设之一。平台能力、数据结构、页面交互和导出流程均不得绑定某个行业、尺寸或固定比例。

本期包含以下八项完整能力：素材与品牌参考、设计需求理解、内容整理与确认、AI 设计与排版、可控修改、多页与版本管理、预览与校稿、专业导出。

本期不包含订金、订单支付、报价、退款、交易担保等交易功能；不包含视频、三维设计、CAD 或软件界面开发。账户组织体系和多人实时协同另行定义，不作为本期验收前提。

## 2. 用户与典型场景

| 场景 | 用户输入 | 预期结果 |
| --- | --- | --- |
| 线上活动海报 | 产品图、Logo、活动文案、风格参考 | 自定义像素尺寸的海报，可修改文案并下载 PNG/JPG |
| 印刷宣传页 | 文案、品牌资料、图片、成品尺寸 | 内容清晰、品牌一致的设计，可下载印刷 PDF |
| 菜单或价目表 | 原图或文字清单、价格、规格、Logo | 可核对内容、局部改价、自动分页，支持线上和印刷交付 |
| 多页品牌介绍 | 多段文案、图片、页面顺序、设计方向 | 多页风格统一，可单独调整页面并整册导出 |
| 已有设计修改 | 选择历史设计，描述需要修改的部分 | 基于指定版本修改，保留未指定的内容与布局 |

## 3. 当前基础与建设重点

截至本草案，项目已具备对话创作、技能选择、多图参考、画布预览、历史版本、会话恢复及当前图片 PNG 下载等基础。参考图已按消息归属保存，不显示在成品版本记录中。

需求制定时，结果主要以位图保存；菜单存在基础结构化校验和固定排版，尚未形成通用可编辑设计文档、多页设计、可靠的局部编辑和 PDF/CMYK 导出能力。本文件描述目标需求，实施进展记录于第 10 节，不表示全部目标能力已实现。

建设重点是让文字、图片、Logo、图形和页面布局具有可持续修改的结构，并由同一份设计稿生成画布预览和下载文件。

## 4. 核心流程

1. 新建创作，描述用途并上传一张或多张素材。
2. 助手理解素材用途，提取内容与设计要求，展示可修改的需求摘要。
3. 用户补充或确认关键内容；也可先讨论方案，不立即生成设计。
4. 助手完成设计与排版，保存设计版本并显示在画布中。
5. 用户通过对话或直接编辑修改内容、样式和位置；可管理多个页面。
6. 校稿，核对内容并处理导出检查发现的问题。
7. 选择线上图片、普通 PDF 或印刷 PDF，检查设置并下载。
8. 后续打开项目，从指定版本继续修改和导出。

## 5. 八项功能需求

### F01 素材与品牌参考

- 支持多图选择、拖放、一次粘贴多图和连续粘贴；保留现有最多 8 张待发送参考图、单张最大 10 MB 的输入能力。
- 首期支持现有 PNG、JPEG、WebP 输入；素材格式扩展不得影响原有输入流程。
- 支持说明和调整素材用途，例如 Logo、产品原图、内容来源、配色参考、布局参考。
- 保留原始文件、文件名及素材身份，设计过程中使用的处理版本不得覆盖原始素材。
- 参考图随对应消息发送；发送成功清空待发送区，发送失败保留草稿。
- 历史消息可查看原始附件；后续修改可沿用指定设计版本关联的素材，不要求重复上传。
- 素材、设计页面和设计版本分别展示；上传素材不新增设计版本，也不占用页面编号。
- 用户提供的 Logo 和产品原图应作为独立素材使用。重新绘制、替换或改变品牌标识需要明确的修改意图。

### F02 设计需求理解

- 从自然语言和素材中提取设计用途、目标受众、内容、品牌、风格、尺寸、方向、页数及交付要求。
- 展示可修改的需求摘要，区分用户明确要求、助手建议和待确认信息；助手自行提出的风格不能自动成为长期约束。
- 支持常用纸张、常用线上画幅和自定义宽高，不固定为 A4、竖版或某个比例。
- 线上用途可用像素描述；印刷用途可用毫米等物理单位描述。界面明确单位，区分成品尺寸与含出血尺寸。
- 支持单页和多页；内容不足以判断页数时，可先给出建议，再由用户调整。
- 支持记录纸张或材质、低墨量、单色等要求，并实际影响设计策略和导出设置。
- 未提供尺寸时，助手可按用途给出可见、可修改的建议，不强制用户先填写完整表单。
- 修改尺寸或用途时，提示其对布局和导出的影响，不在后台无提示地裁切内容或变更比例。

### F03 内容整理与确认

- 支持标题、副标题、正文、列表、联系方式、行动引导等通用内容，保留与原始输入的对应关系。
- 对菜单、价目表等场景，支持分类、名称、价格、单位、规格、说明及不同规格对应价格的结构化编辑。
- 从图片中提取文字时，标出无法确认的内容，保留来源供对照；不得猜测后直接作为已确认内容。
- 用户可在内容面板修改、补充、删除或调整顺序；内容变更同步到设计稿。
- 检查缺失内容、重复条目和格式异常，展示具体条目，不只提示“校验失败”。
- 不擅自省略、改写用户已确认的名称、数值、活动条件或联系方式。
- 用户明确接受的空值或特殊格式可以保留；仍处于待确认状态的关键内容应在定稿检查时明确提示。

### F04 AI 设计与排版

- 根据用途、内容量、品牌和参考图，自主安排视觉层级、字体、配色、留白、构图和图文关系。
- 支持极简、复古、品牌定制等不同设计方向，不将风格等同于固定几组配色。
- 能将 Logo、产品图及其他指定素材实际放入设计，而非仅作为理解参考。
- 文字、Logo、图片、基础图形和布局保持独立的编辑能力；需要准确交付的文字由排版流程绘制。
- 图片生成可用于背景、插画和装饰等视觉素材；生成素材与已确认文字共同组成设计稿。
- 支持换行、文本框尺寸计算、对齐、间距、分栏和图片裁切，避免文字与图片相互遮挡。
- 内容过多时调整布局或分页，不通过静默省略内容来适配页面。
- 支持保留用户指定的视觉元素和原有分类、顺序；重新设计时说明主要变化。
- 单纯讨论方向或整理内容时不自动出图；生成数量和任务状态清晰可见。

### F05 可控修改

- 支持通过对话指定对象或范围，例如“只改标题”“第二页换图”“保留布局，换成品牌色”。
- 支持选中对象后直接修改文字、数字、字体、字号、颜色、对齐、位置和尺寸；支持替换图片和 Logo。
- 首期提供基本对象编辑与属性面板，不要求完整复刻专业桌面设计软件。
- 对结构化设计稿的文字和价格修改，通过排版更新完成，不强制重新生成整张图片。
- 局部修改应保留范围外对象的内容和样式；确需连带移动、换行或分页时展示原因及影响范围。
- 支持撤销和重做；直接编辑会保存为草稿，可生成明确的设计版本。
- 从历史版本继续修改形成新版本，原版本保持可查看和可导出。
- 对已有整张位图，明确其可编辑范围；不得声称导入图片后已经自动获得准确文字图层。

### F06 多页与版本管理

- 一个设计文档可包含多个页面；同一文档的各页可采用统一尺寸，也可按需要设置页面尺寸。
- 支持新增、复制、删除、排序和重命名页面；页面删除可撤销。
- 内容超出页面时支持自动分页，保留必要的分类、阅读顺序和连续关系；用户可以手动调整分页。
- 多页共享品牌、字体、主色及基础版式，允许页面局部覆盖。
- 页面列表表示设计内容顺序；版本记录表示设计修改历史，两者使用独立编号和入口。
- 一个设计版本保存完整文档快照，包含全部页面、内容、素材引用与相关设置；切换版本恢复对应状态。
- 删除或替换当前稿中的素材，不得破坏历史版本所需的素材。
- 下载可选择当前页、指定页或全部页面；页序与当前版本一致。

### F07 预览与校稿

- 支持适应画布、缩放、页面切换，以及内容与来源对照。
- 支持比较两个设计版本，查看视觉差异及关键文字、数值的变化。
- 支持显示成品边界、安全区域和出血区域，明确哪些辅助线不会进入最终文件。
- 导出前检查文字溢出、缺失素材、字体和字符问题、图片有效分辨率及色彩设置。
- 检查结果可定位到具体页面和对象，区分必须处理的问题与可确认后继续的提醒。
- 纸张材质模拟属于辅助预览；模拟纸色默认不进入印刷文件，除非用户明确将其作为设计背景。
- 屏幕预览与实际纸张、设备的差异应在相关预览说明中表达，不承诺屏幕颜色与实物完全一致。

### F08 专业导出

#### 5.8.1 下载类型

| 下载选项 | 用途 | 首期要求 |
| --- | --- | --- |
| PNG，RGB | 线上发布、透明背景图片、单页预览 | 必须支持 |
| JPG，RGB | 线上发布、体积较小的图片 | 必须支持 |
| 普通 PDF，RGB | 分享、查看、多页校稿 | 必须支持 |
| 印刷 PDF，CMYK | 印刷交付 | 必须支持 |
| TIFF，CMYK | 指定印刷流程的图片交付 | 后续增强 |

文件格式与色彩模式分别设置。界面只提供实际支持的组合，不提供“CMYK PNG”。PDF、TIFF 等格式的色彩支持见参考资料 R1、R2。

#### 5.8.2 通用下载设置

- 快捷预设为“线上图片”“普通 PDF”“印刷 PDF”；高级参数按需展开。
- 显示导出的设计版本、页面范围、尺寸、单位、文件格式、色彩设置和检查结果。
- 图片支持输出像素尺寸及清晰度设置；印刷支持实际成品尺寸与栅格内容的输出分辨率设置。
- 多页 PDF 保持页面顺序和每页尺寸；多页图片可以按页打包下载。
- 下载读取确定的设计快照；导出期间继续编辑，不影响该次下载所对应的内容。
- 命名包含项目、版本及必要的页面信息；导出显示进度、成功或失败状态。
- 生成失败时保留稿件和设置，可重试；不得改扩展名伪装格式，也不得静默换成其他色彩模式。

#### 5.8.3 高清与文字要求

- 在结构化设计稿导出的 PDF 中，保留可保留的矢量文字、线条和图形，并嵌入所需字体或字体子集。（R1、R3）
- “高清”按成品尺寸和素材的有效分辨率检查，不以 PDF 扩展名、文件大小或放大图片像素作为判断依据。（R4）
- 首期印刷检查建议默认采用 300 PPI 阈值，可按用途或印刷要求调整；该数值是平台预设，不是适用所有印刷场景的固定要求。
- 低清原图或整张位图不能因转成 PDF 自动变为矢量或恢复细节；导出时保留相关提醒。

#### 5.8.4 CMYK 与印刷要求

- 支持选择目标 ICC 色彩配置，展示预设适用的输出条件；支持导入或选用印刷方提供的配置。（R1）
- 执行实际颜色转换，并正确写入目标色彩信息；不能只改文件名、标签或元数据。（R1）
- 首期 CMYK 印刷预设应按定义检查输出对象的色彩空间及允许的灰度对象，不能只凭 PDF/X 标识认定已完成 CMYK 转换。（R3）
- 对需要保持的单黑文字提供相应导出策略，并纳入输出检查；具体转换策略应记录在导出设置中。
- 支持成品尺寸、可配置出血和可选裁切标记；不同印刷要求使用相应预设，不把某个出血值固定应用于全部设计。（R1）
- 提供明确、经过验证的印刷预设。PDF/X-4 作为首期标准预设目标；只有通过相应符合性检查的文件才能显示该标识。（R3）
- 普通 CMYK PDF 与 PDF/X 符合性分别展示；选择 PDF/X 预设后，符合性检查失败应阻止以该预设交付。
- 出血内容应由设计延展或明确的背景规则生成，不简单拉伸成品边缘来掩盖缺失内容。

## 6. 下载检查规则

| 检查项 | 默认处理 |
| --- | --- |
| 文字溢出、缺失素材、关键字符无法绘制 | 阻止受影响文件导出，定位到页面和对象 |
| 印刷所需字体无法嵌入且没有有效替代方案 | 阻止印刷导出，提示更换字体 |
| 仍未确认的关键内容，如价格、联系方式 | 提示确认；确认后记录用户选择，再允许定稿下载 |
| 图片有效分辨率低于所选预设 | 显示实际值与目标值；用户可确认后继续，保留提醒 |
| CMYK 目标配置缺失、无效或转换失败 | 阻止 CMYK 导出；不得静默输出 RGB |
| 所选 PDF/X 预设符合性检查失败 | 阻止按该预设交付，展示可处理的问题 |
| 出血范围缺少必要背景内容 | 定位问题；修复或明确修改出血设置后重试 |

检查应覆盖实际输出文件，不仅检查界面设置。PDF/X 相关规则以选定标准及校验工具的结果为准，不能用“能打开 PDF”代替符合性验证。（R3、R5）

## 7. 页面与交互要求

保留现有“左侧沟通、右侧画布”的主体结构，围绕设计任务增加以下入口：

| 区域 | 主要内容 |
| --- | --- |
| 对话区 | 需求沟通、历史附件、任务状态及修改说明 |
| 需求摘要 | 用途、尺寸、风格、页数、品牌和交付要求，可修改 |
| 内容面板 | 通用文案及场景结构化内容，可与来源对照 |
| 画布与属性面板 | 页面预览、对象选择、直接编辑及属性调整 |
| 页面列表 | 当前文档的页面、顺序与页面操作 |
| 版本记录 | 成品设计历史、比较及从指定版本继续修改 |
| 下载面板 | 使用场景预设、页面范围、高级设置和检查结果 |

尺寸入口提供预设和自定义选项。专业参数在需要时展开；用户可以先对话、先讨论，不必先完成一份大型表单。小屏界面采用切换或抽屉展示面板，保持画布和主要操作可用。

## 8. 数据与可靠性要求

- 设计稿统一保存页面、对象、文字样式、素材引用、需求摘要及导出设置；预览和导出使用同一份内容与布局。
- 区分原始素材、生成素材、设计稿、设计版本和导出文件，避免混用编号或互相覆盖。
- 重要编辑及时保存，刷新后可恢复；导出失败不丢失设计稿，任务中断不显示为成功。
- 历史版本不可被后续编辑覆盖；生成版本时记录所用素材和关键设计设置。
- 兼容已有会话和位图版本：可继续查看、下载或作为素材使用，清楚呈现实际可编辑和可导出的范围。
- 用户上传的品牌素材、文案与项目文件按项目访问边界处理；不进入不相关创作，也不公开分享。
- 处理失败展示具体原因和下一步操作；未实际完成的格式转换、校验和下载不能显示为成功。

## 9. 验收场景

八项核心能力均属于首期范围，以下场景用于检查完整流程，不能只验收按钮或配置表单。

| 编号 | 场景与操作 | 通过条件 |
| --- | --- | --- |
| AC01 | 上传产品图、Logo、风格参考后发送消息 | 图片完整进入该消息；待发送区清空；素材不进入成品版本记录 |
| AC02 | 制作自定义像素尺寸的线上活动海报 | 画布和输出尺寸符合设置；标题可直接修改；PNG/JPG 下载正常 |
| AC03 | 制作自定义毫米尺寸的印刷宣传页 | PDF 成品页面尺寸正确；出血和裁切设置与所选参数一致 |
| AC04 | 制作另一种纸张预设的价目表，例如 A4 或 A3 | 与自定义尺寸共用同一设计流程，不存在只支持 A4 的限制 |
| AC05 | 输入含模糊文字、缺失价格或重复项目的清单 | 具体问题可定位；未经确认不作为准确内容交付；确认后的内容无遗漏 |
| AC06 | 设计中使用用户 Logo，随后只改标题或一个价格 | Logo 来自指定素材；局部编辑保留其他内容和样式；不强制重新生成整张图 |
| AC07 | 内容超出单页，生成并调整至少三页文档 | 无静默裁切或遗漏；顺序、分页和统一风格可检查；整册 PDF 页序正确 |
| AC08 | 对第三页修改后，切换旧版本并继续编辑 | 页面编号与版本编号独立；旧版本完整保留，新修改形成新版本 |
| AC09 | 输出普通 RGB PDF 与 CMYK 印刷 PDF | 同一版本内容一致；真实文件的色彩、字体、页面尺寸等符合各自预设 |
| AC10 | 导出含矢量文字与低清位图的设计 | 矢量文字保持相应输出能力；按实际成品尺寸提示低清素材；不虚报高清 |
| AC11 | 选择 PDF/X-4 预设下载 | 输出通过相应校验；失败时不提供带合规标识的结果 |
| AC12 | 设置牛皮纸预览和低墨量设计 | 模拟纸色不被误当成待印背景；实际文件符合确认的低墨量设计要求 |
| AC13 | 导出期间继续编辑，或发生字体、转换、任务失败 | 该次下载内容对应固定版本；失败状态真实，稿件和设置可恢复 |
| AC14 | 打开已有整张位图版本 | 原文件仍可用；不虚报独立文字图层、矢量细节或已完成印刷处理 |

验收应使用真实输出文件进行页面属性、字体、色彩空间、配置和符合性检查，并对照渲染结果核对内容。新功能的验证优先使用固定样例与本地检查，真实模型验证作为受控补充。

## 10. 首期与后续增强

### 首期必须覆盖

- 八项核心能力的基础闭环，包含通用尺寸、独立内容与素材、局部编辑、多页、版本、校稿及专业导出。
- PNG/JPG、普通 RGB PDF、CMYK 印刷 PDF，及经过验证的 PDF/X-4 导出预设。
- 导出文件与设计版本一致，内容与布局可检查，不以整图重新生成为所有修改的唯一方式。

### 后续增强

- TIFF CMYK、SVG 等更多交付格式，以及更多 PDF/X 变体。
- SVG/PDF 等素材输入、品牌素材库、可复用模板及跨项目品牌设置。
- 一套设计适配多个尺寸、批量物料生成、更丰富的对象编辑和高级排版。
- 客户分享、评论批注、多人实时协作和组织空间。
- 专色、白墨、刀模、包装工艺等专门印刷流程，另行定义。

### 开发优先级与依赖

开发顺序按共同依赖、用户可用性和技术不确定性安排。八项核心能力均需交付，但不要求八个模块同时完整开发。以下顺序不构成工期承诺。

| 顺序 | 开发内容 | 为什么排在这里 | 阶段验收结果 |
| --- | --- | --- | --- |
| 1 | 通用设计文档契约与渲染、印刷导出技术验证 | 局部编辑、多页、版本和专业导出共同依赖设计稿结构；字体和印刷链路的可行性需要尽早确认 | 固定样例包含中文、Logo、图片和图形；在自定义像素尺寸及物理尺寸下，验证预览、矢量 PDF、字体和 CMYK 输出；明确 PDF/X 校验路径 |
| 2 | 单页可编辑设计与内容排版 | 先证明设计稿可修改、可保存、可一致输出，为 AI 提供可靠操作对象 | 可修改文字、颜色、字号、位置和图片；换行与溢出检查有效；刷新恢复；保留基本版本；同一稿件可输出 PNG/JPG 和普通 PDF |
| 3 | AI 需求理解、内容整理和通用设计操作 | 文档与排版稳定后，AI 可以通过明确操作创建和修改设计，减少每个技能维护独立出图流程 | 上传多份素材后形成需求摘要及可编辑设计；对话可以定位对象并局部修改；通用能力至少验证海报和列表类设计两种不同场景 |
| 4 | 多页排版与完整文档版本管理 | 在单页对象、编辑和保存行为稳定后，扩展到分页与整册操作 | 自动分页和页面排序有效；整册快照可恢复；页面编号与版本编号独立；至少三页样例内容完整 |
| 5 | 专业导出产品化与文件检查 | 基于前面已验证的引擎，完成用户可使用的印刷交付流程 | 支持页面范围、实际尺寸、出血、ICC、CMYK 转换、字体与分辨率检查；PDF/X-4 预设通过校验；失败不交付伪合规文件 |
| 6 | 模板、品牌复用及批量适配等增强 | 在基础设计和交付闭环稳定后，提高复用和生产效率 | 以独立需求验收，不阻塞首期核心闭环 |

第 1 步只做足以支持技术选择的最小原型与文件验证，不先建设大型通用框架。第 5 步负责完整交互、任务处理和实际文件验收；CMYK 和 PDF/X 的技术可行性必须在第 1 步确认，避免到交付阶段才发现引擎能力不足。

### 最先落地的开发单元

第一个开发单元为“通用设计文档与单页渲染样例”，产出以下共同契约和验证结果：

1. 文档包含版本化结构、页面数组、独立对象、尺寸与单位、素材引用及导出设置。首次只操作一页，但数据结构从开始即支持多页。
2. 对象最少支持文字、图片和基础图形；Logo 作为独立素材放置。区分可编辑对象和整张位图，兼容已有图片版本。
3. 素材、设计稿、设计快照和导出文件分别管理；现有会话继续保存沟通记录，通过关联引用设计稿，保留已有会话和素材。
4. 排版层统一计算文本尺寸、换行、位置和溢出，预览与导出共享同一份排版结果。
5. AI 与手动编辑最终使用同一组经过校验的文档操作；设计技能提供方法和场景约束，渲染、保存、导出由平台公共能力承担。
6. 用固定样例验证中文字体、矢量文字、Logo、图片裁切、物理尺寸、CMYK 转换及输出检查；以真实文件结果决定引擎方案，不提前固定具体库。

建议在现有应用中拆分文档、素材、排版、渲染和导出职责，复用现有对话、模型适配和任务状态能力。基础契约确认后，可在不改变契约的前提下分别完善编辑交互和导出实现。

### 第一个用户可用里程碑

第 2、3 步完成后，用户应能完成“上传素材 → 描述用途与自定义尺寸 → 生成单页可编辑设计 → 直接或通过对话修改指定文字 → 保存版本 → 下载图片或普通 PDF”。

该里程碑须同时验证线上海报与印刷宣传页两类尺寸和内容需求，不依赖某种纸张或行业。首期最终交付还需完成第 4、5 步的多页与专业印刷能力。

- 清单、价目表的重复条目支持按真实字体测量自动分栏分页，手动录入及 AI 共用同一引擎；标题/Logo 逐页复用，原页保留、结果追加。单条放不下或超过上限时原子拒绝，保留内容来源和待核对状态。复杂图文自动排版、分类续页规则和批量品牌样式尚未交付。

- 印刷 PDF 生成后重新检查页面框、嵌入字体、图形/图片色彩空间和目标 ICC；损坏配置或转换回退会拒绝，未通过检查不交付。检查与下载使用确定 revision 的内容快照，文件名含版本和页码，失败保留设置。默认 ICC 仍为技术验证配置，适用输出条件须由印刷方确认。

- 已补齐基础画布编辑：独立对象选中、拖动、四角缩放、Shift 等比例、键盘微调、页面对齐及边缘/中心吸附；未保存页面与文本框可即时预览。文字字形、换行、基线与导出使用同一服务端排版引擎，草稿排版接口只读。属性、内容绑定、对象和页面操作共用窗口内撤销/重做；按输入焦点合并连续输入，单次拖动记录一步，取消手势不修改文档。保存保留历史，外部/AI 文档更新与会话切换重置历史，避免跨稿覆盖。多选、旋转与刷新后的撤销历史恢复尚未交付。
- 已补齐图片替换、对象复制和基础图层：现有素材或新上传原位替换图片/Logo，保留框与出血设置，原素材及版本保留；替换上传独立于聊天参考图。复制生成独立绑定内容，保留来源和核对状态。列表与画布从前到后对应，支持置顶/置底/逐层调整、锁定/隐藏；锁定保护手动与 AI 对象编辑，隐藏从画布、吸附、图片、PDF 和印刷检查中排除，仍保留文档、历史和本机草稿。未提供多对象分组、批量操作与拖拽图层排序。
- 已补齐自动保存与本机恢复：编辑停顿 1.2 秒后更新当前稿；后台保存不锁定编辑，返回结果保留请求期间的新修改，手动保存、下载与 AI 提交等待同一串行保存队列。连续输入撤销分组与历史快照分开，不因自动保存产生版本。IndexedDB 按窗口独立保留整册草稿，恢复入口展示时间、页面数，保留来源和绑定；失败、离线、存储不可用均提供具体状态、重试或 JSON 备份。恢复旧 revision 时暂停同步，不覆盖最新稿；重新载入和切换会话保留本机未同步内容。尚未提供冲突自动合并、跨浏览器恢复或 JSON 草稿重新导入。
- 已补齐「图片创作」的对话尺寸目标：准确像素和宽高比分开记录，输入区展示确认目标，可手动调整/取消，跨轮与刷新保留，历史图片版本记录并恢复各自目标。生图仍使用配置的服务商 size，提示词明确构图比例，返回后检查实际像素并保证目标交付；默认等比完整保留并留边，明确选择后才居中裁切，不拉伸。展示适配和放大信息，适配前图片独立保留供下载，不混入版本记录；默认图片下载来自符合目标的交付文件。当前未实现任意比例的原生模型生成、智能扩图、多尺寸批量设计或可编辑设计模式的对话改尺寸。
- 上述 AI 链路使用真实 SDK 和模拟模型响应进行自动化验证，真实模型的识别和设计质量尚需实际素材验收。软打样、更完整的专业印刷预检和独立 PDF/X-4 符合性验证仍未交付，第 5 步尚未全部完成。当前环境没有可运行的独立 PDF/X 校验工具，因此继续输出普通 CMYK PDF，不开放 PDF/X-4 标识；独立校验路径仍待验证。
