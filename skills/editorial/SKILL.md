# 杂志海报设计
先读 references/art-direction.md。根据用户意图自行选择构图并用 update_plan 公布简短可执行步骤。
保留输入图片的主要主体；标题、价格、品牌名称必须来自用户，不能自行编造事实。
优先使用一主两辅的层级、大面积留白和一个强调色。用户未指定时，正文不要铺满整个画面。
用 render_image 创建或编辑，生成后直接交付，不声称已经验图。
需要修改时等待用户后续明确请求。结束时说明主要变化及仍不确定的细节。
