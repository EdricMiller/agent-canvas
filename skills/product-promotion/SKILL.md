# 商品推广设计

本技能提供设计方法、参考与工作知识。具体场景、构图、字体、图文关系、文字多少和实现方式，由 Agent 根据用户本轮想要的结果判断。参考案例是方法来源，不是模板清单。

## 理解需求与商品

先理解商品、使用场景、想传达的感受和必须保留的信息。只讨论时直接讨论，不出图。用户给出实拍和一句需求时，自主完成合理的创意判断；关键缺失信息确实影响目标时才集中询问，不强迫用户先选背景、风格或版式。

区分商品事实与创意设想。用户明确提供的信息为 user，可见外观为 observed，无法确定的为 unknown。不凭外观编造材质、品牌、工艺、产地、价格、优惠或功效。需要判断实拍保留范围时读取 references/product-fidelity.md。

## 运用方法形成具体画面

首次制定视觉方向，或用户对单调、风格和排版提出反馈时，读取 references/art-direction.md。组织推广信息时读取 references/promotion-design.md，考虑摄影表现时读取 references/photography.md。按本轮问题选读，不遍历全部文件。

先明确观众这次需要感受到、理解或记住什么，再决定用怎样的画面实现。把用户描述的感受落实为可见的选择：商品如何出现，视角与尺度如何组织注意力，光线、人物、环境与商品是什么关系。创意应能用简短的设计说明连接到用户目标，不要求用户先从多个风格方案中选择。

然后判断文字是否承担具体传播任务。用户说“宣传图”不等于要求主标题加副标题；仅展示佩戴、使用效果或商品质感时，先考虑画面能否独立传达诉求。需要准确活动信息、品牌识别、明确卖点或用户指定文字时，再组织相应信息。图上文案可以创作，但给画面起一个诗意名字不是必须把它放上图的理由。不要为了补齐海报形式自动添加口号，也不要把所有需求一律处理成无字图。

确定有文字后，再根据视觉焦点和阅读顺序安排图文关系，不默认顶部留白、左上标题或上文下图。文字的尺度、位置、字形、色彩和间距共同服务本轮表达。无文字时，不为标题预留一块无意义的空白。

文案、色彩、构图和字体需形成适合本轮诉求的整体。高级、温柔、年轻或有力量等感受都需要结合商品和语境判断，不能直接翻译成一套固定配色、字体和道具。可以克制留白，也可以场景叙事、字体主导或强调信息；示例文案与案例外观均不是默认答案。

save_product_brief 可按需记录本轮方案与商品依据：brief 说明创意和保留范围，campaign 记录实际文案与具体视觉。theme 是方案主题，不要求出现在图片上；headline、subtitle、cta 等只记录本轮真正要上图的文字，不用的字段留空。重新设计时更新已过时的视觉说明与文案，可用空字符串或空数组清除不再采用的内容，商品事实继续保留。它是上下文记录，不是必须填完的表单，kind 也不决定视觉风格。

## 理解修改的范围

区分商品本身、用户确认过的品牌规范与用户偏好，以及 Agent 上一轮自行选择的视觉方案。上一版采用的配色、字体、标题和道具，不自动成为用户要求。历史图用于理解反馈、定位需要改进的地方，不能单凭存在历史版本就要求沿用其风格。

用户明确要求局部修改或保留某部分时，尊重这个范围，延续已确认的要素。用户说“有些单调”“换个感觉”“重新设计”，或指出整体风格问题时，重新判断造成问题的画面关系：视觉焦点、构图节奏、光影、配色、图文安排是否支持新的目标。改变摆放方式或换成佩戴，并不自动意味着已经解决整体单调的问题。

按用户的具体反馈决定哪些设计选择值得保留、哪些需要重做；不强制每轮换色，也不为了不同而随机换风格。继续沿用某个要素，应有用户要求、已确认规范或本轮设计目标作为理由。形成一个连贯方向后执行，向用户说明主要变化即可，不展示内部推理，不自动增加方案数量。

## 执行与修改

请求制作时，展示简短行动计划，再用 render_image 生成或编辑。提示应描述用户想要的完整画面，包含本轮需要的图文关系、实际文字与商品保留要求；不需要文案就明确不加文案，不把方案说明画在图上。没有本地模板或固定分区流程，版式由 Agent 的本轮设计决定。

sourceId 表示正在延续的设计版本；有商品原图时，图片工具固定使用实拍作为实际编辑输入。需要延续当前版本的内容应在提示中描述，不能承诺重绘后商品像素一致。概念图不是已核实实物。

文字也由图片模型处理，没有独立文字图层。修改文案时按用户的新请求编辑图片，不承诺无生图即可改字或画面完全不变。准确价格、品牌和必需文案应使用用户提供的原文，并如实说明无法确认之处。

画幅根据用途、投放位置和画面描述自主安排，用户明确指定比例时优先遵循，不要求用户先选择尺寸。可通过 save_product_brief 的 size 记录目标画幅，实际像素尺寸以图片接口返回为准。

数量、比例和风格服从用户需求。默认每轮一张，只有本轮明确要求多张才增加数量；失败的生图请求也占次数。工具返回后直接交付，不为同一张图自动追加排版、验图或返工，不把工具执行成功当成设计质量合格。

交付时说明本轮创意与主要变化，不声称已经核对商品一致性，等待用户下一条明确修改需求。
