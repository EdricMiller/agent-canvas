# 商品推广方案

先理解“推广什么、希望传达什么、在哪里使用”。用户只提供实拍与一句“做宣传图”时，由 Agent 判断适合这件商品和本轮诉求的表达，不强迫填写表单或先选三种方向。下表帮助组织信息，不是类别到视觉风格或制作方式的映射。

| 用途 | 重点 | 方案原则 |
| --- | --- | --- |
| awareness 主题宣传 | 建立商品印象 | 用商品、场景和必要信息建立识别，不预设标题与副标题 |
| features 卖点展示 | 说明已知特点 | 使用有依据的外观或用户提供的特点，不用观察猜材质；数量服从用户需求 |
| promotion 活动促销 | 传达真实交易信息 | 用户提供的价格、活动条件与品牌准确呈现；缺少价格时不编造优惠 |
| lifestyle 场景种草 | 展示搭配与使用感 | 场景应与商品相容；佩戴比例或背面结构不明时保留不确定性 |

campaign 用于记录最终方案，不是内部推理。goal 描述传播目的；theme 是指导创作的主题，不必写在图上；headline/subtitle 是本轮确定要上图的文字；sellingPoints 是有依据的卖点；visual 描述具体画面关系与表现方式。无新增文字的方案将相关文案字段留空；重新设计时清除不再采用的旧文案与视觉说明。audience 缺乏资料时可写拟定的设计对象，不能当成已证实的市场研究。

品牌、价格、折扣、功效与材质必须来自用户明确提供的信息。观察到的珠光、颜色或轮廓可描述为外观，不据此确认天然贝母、玉石、纯银、手工工艺或健康功效。创意文案可以表达气氛，不捏造事实。

sellingPoints 使用 facts 中已知资料的原文或连续片段，不引用 unknown 项。brand 与 offer 须能在 user 资料中找到对应原文；没有依据就留空。主题标题与辅助创意文案不受逐字引用限制，但同样不得虚构事实承诺。

主题应随商品与目的变化：饰品可用细节、穿搭与礼赠氛围，食品可用口味信息和食用场景，家居用品可展示使用环境。以上是方向，不能替代真实资料或成为固定模板。

交付说明本轮采用的表达方式与主要改动；有实际图上文案时再说明文案。无独立验图时不声称商品已经核对通过。只制作用户要求的数量，默认一张。
